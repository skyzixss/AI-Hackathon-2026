# Скиллы и плагины команды

Общие скиллы находятся в `.agents/skills/` и приходят с клоном репозитория:

- `$portal-data` — изменения схемы, API и правил доступа;
- `$portal-ui` — интеграция экранов и проверка интерфейса;
- `$portal-handoff` — передача задачи и проверяемых результатов через Issues/PR.

Это инструкции для ассистента, а не установленные сервисы. После обновления
проекта проверьте доступность скиллов в своей сессии; если они ещё не обнаружены,
откройте новую сессию в каталоге репозитория или явно дайте путь к SKILL.md.
У другого ИИ-клиента механизм обнаружения может отличаться.

## Минимальные подключения

| Плагин | Кому нужен | Проверка |
| --- | --- | --- |
| GitHub | Всем | Прочитать свой Issue и актуальный PR; локально gh auth status и git ls-remote origin HEAD |
| Supabase | skyzixss; другим достаточно URL + publishable key для SDK | Просмотреть проект и таблицы; доступ к dashboard не требуется UI-коду |
| Cloudflare | skyzixss | Прочитать список аккаунтов; не развёртывать без готового build |

В чате skyzixss чтение GitHub, Supabase и Cloudflare проверено.
Проект Supabase создан. Установки/доступы на компьютерах остальных участников
не проверены. Они подключают плагины в своём ассистенте под своим аккаунтом.
Не передавайте токены через Issue или репозиторий. Плагин не заменяет
авторизацию локального Git или CLI.

Без плагина GitHub можно использовать авторизованный gh; Supabase — через
CLI/dashboard и SQL миграции; Cloudflare — через локальный Wrangler владельца.
Это альтернативы, не автоматическая передача полномочий между участниками.

Не нужен отдельный плагин для React/TypeScript. npm зависимости уже закреплены
в lock-файле. Для браузерной проверки использовать доступный в сессии инструмент
браузера; если его нет, честно запросить ручную проверку 360 px и клавиатуры.
