## Сборка и проверка

[Генератор](build_report.py) читает два источника выше и выбранные изображения
из docs/design, docs/releases и docs/session-a11y. Нужны Python 3.9+,
ReportLab, Pillow и pypdf, шрифт Arial (macOS) либо DejaVu Sans (Linux).
Это отдельные инструменты подготовки документа, они не входят в приложение
и не меняют его зависимости. В текущей среде использованы уже установленные
пакеты; новые зависимости и глобальные настройки не добавлялись.

```sh
python3 docs/process/build_report.py
```

Результат по умолчанию: output/pdf/campus-ai-process-draft.pdf.
Можно передать другим первым аргументом путь вывода. После проверки страниц
копия результата сохранена рядом с исходниками для review в репозитории.
[Состав и SHA-256 текущей копии](report-manifest.json).

Для проверки экспорта: открыть PDF заново, извлечь текст, проверить число
страниц и ссылки, отрендерить все страницы через Poppler и просмотреть.
Перед публикацией проверить исходники и извлечённый текст на приватные значения.
Повторная сборка может менять метаданные PDF и его SHA-256; обновлять копию
и manifest только после новой проверки.
