# MGIMO AI Challenge 2026

Стартовый репозиторий команды для хакатона. Прикладной стек пока не выбран.

Репозиторий: https://github.com/skyzixss/AI-Hackathon-2026

## Инструменты

- Node.js: ветка 24 LTS; версия для менеджеров Node указана в `.nvmrc`.
- Python: 3.14.7; потребуется установленный uv.
- Локальное Python-окружение: `.venv`, создаётся через uv и исключено из Git.
- VS Code выбирает интерпретатор `.venv/bin/python`.
- Git: основная ветка `main`.

Первый запуск после принятия приглашения в GitHub:

```sh
git clone https://github.com/skyzixss/AI-Hackathon-2026.git
cd AI-Hackathon-2026
uv venv --python 3.14.7 .venv
code .
source .venv/bin/activate
python --version
node --version
npm --version
```

На подготовленном Mac репозиторий уже находится в папке
`/Users/anton/Desktop/AI-Hackathon-2026`, окружение `.venv` уже создано:
повторно клонировать репозиторий и создавать окружение не нужно.

До установки библиотек согласуйте версию Python с их требованиями. Зависимости приложения пока
не установлены; добавьте общий файл зависимостей и lock-файл после выбора стека.

## Совместная работа

1. Принять приглашения в закрытый репозиторий GitHub.
2. Клонировать его на компьютеры участников.
3. Для каждой задачи создавать отдельную ветку и объединять изменения через PR.
4. Не давать нескольким ассистентам одновременно менять одни и те же файлы
   в одном рабочем каталоге; использовать отдельные ветки и рабочие копии.
5. Хранить ключи в локальном `.env`; в `.env.example` указывать только названия
   переменных и пустые значения. `.gitignore` не заменяет проверку перед коммитом.

GitHub CLI: проверить вход командой `gh auth status`.
Если вход отсутствует, выполнить `gh auth login --web` в своём терминале.

Docker и PostgreSQL пока не нужны для проверки базового окружения.
